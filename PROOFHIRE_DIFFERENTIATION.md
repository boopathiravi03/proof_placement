# ProofHire 2.0 — Competitive Differentiation Matrix

This matrix compares general system archetypes based on their typical primary design focus, without naming or making unsupported claims about specific commercial vendors.

| Capability | Traditional Placement Portal | Resume-Based Recruitment | Standalone Skill Assessment Tool | Learning Management System (LMS) | **ProofHire 2.0** |
|---|---|---|---|---|---|
| **Evidence-Backed Competency Lifecycle** | Rarely (usually static profile/CGPA) | Unverified resume bullets | Point-in-time test score only | Course completion certificates | **6-state lifecycle** (`Claimed` -> `Observed` -> `Evidence-linked` -> `Assessed` -> `Verified` -> `Expired`) |
| **GitHub / Artifact Policy** | Usually external URL only | Link on PDF resume | Not typically integrated | Assignment upload only | **GitHub alone -> `Evidence-linked`, never `Verified`** |
| **Adaptive Competency Assessment** | Not core | Not core | Core feature (often isolated from campus drives) | Basic quizzes | **10-category adaptive difficulty** tied directly to skill states |
| **Skill-Gap & Learning Closure** | Not core | Not core | Gap score without remediation | Course catalog without drive context | **Topological prerequisite paths** + evidence submission + reassessment |
| **Explainable Eligibility & Matching** | Binary CGPA/backlog filter | Keyword/ATS ranking | Candidate test ranking | N/A | **Versioned rules**, rule-by-rule explanations, **compatibility separated from eligibility** |
| **Institutional & Accreditation Analytics** | Basic placement counts | None | Cohort test averages | Course completion metrics | **Branch gap heatmaps, interventions, `k < 3` privacy, NAAC/NIRF snapshots** |
| **Trust, DPDP Privacy & Audit** | Basic admin logs | Limited student control | Standard account settings | Standard LMS permissions | **6-category consent, DPDP export/erasure, four-fifths fairness, SHA-256 + HMAC audit chain** |
