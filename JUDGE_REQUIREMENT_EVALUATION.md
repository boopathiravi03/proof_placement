## Most Important Missing Requirements
1. Mandatory JWT enforcement (`get_current_user`) across all protected endpoints instead of `get_current_user_optional`.
2. Production environment guard on `POST /api/audit/{college_id}/tamper`.
3. Live containerized code-execution sandbox (currently AST + simulated runner).
4. Automated Playwright browser E2E suite.
